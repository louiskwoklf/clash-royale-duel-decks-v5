Safari bookmarklet

RoyaleAPI search bridge

Install the bookmarklet once, then use it to send RoyaleAPI candidates back to this Finder tab. Imported data clears when this page is refreshed or closed.

  1. In Safari, choose View → Show Favorites Bar.
  2. Remove the older Finder bookmarklet, then drag the orange button below into the bar.
  3. Configure all four decks and click Open all RoyaleAPI searches.
  4. Wait for each result page, then click the bookmarklet. Each tab closes after the Finder receives its data.
